# Tower of Hanoi

A Rust implementation of the Tower of Hanoi puzzle using recursion.

## Features

- Recursive algorithm
- Reads the number of disks from user input
- Displays every move
- Includes automated tests

## Project Structure

```
tower_of_hanoi/
├── src/
│   ├── lib.rs
│   └── main.rs
├── tests/
│   └── hanoi_tests.rs
├── Cargo.toml
├── Cargo.lock
└── README.md
```

## Run the Project

```bash
cargo run
```

## Run the Tests

```bash
cargo test
```
