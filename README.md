# Tower of Hanoi

A Rust implementation of the Tower of Hanoi puzzle using recursion.

## Features

- Recursive algorithm
- Reads the number of disks from user input
- Prints each move
- Includes automated tests

## Project Structure

```
tower_of_hanoi/
├── src/
│   ├── lib.rs
│   └── main.rs
├── tests/
│   └── hanoi_tests.rs
├── Cargo.toml
└── README.md
```

## Run the project

```bash
cargo run
```

## Run the tests

```bash
cargo test
```
